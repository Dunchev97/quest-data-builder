# Велесова ночь Диалоги в начале истории и в конце квестов

Редакция для проверки.

Всего 13 диалогов: вступительный разговор отдельным первым таском квеста 1 и по одному финальному разговору последним таском каждого из 12 квестов.

Порядок в списке квеста 1: вступительный разговор → три существующих таска → финальный разговор → завершение квеста. Для квестов 2–12: три существующих таска → финальный разговор → завершение квеста. По указанию пользователя порядок выполнения не ограничен: у экшенов только active_quest соответствующего квеста, без проверки завершения других тасков.

Каждый раздел ниже — один непрерывный диалог. В нём не больше двух говорящих персонажей. Домовёнок участвует в событиях через помощь и выполнение тасков; его портрет и реплики не добавляются. Ремарки описывают события вокруг разговора и не являются отдельными окнами.
