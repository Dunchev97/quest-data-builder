# Архив переданной сборки

Здесь сохранены оригинальные машинные файлы, полученные при переносе работы другого геймдизайнера. Все перемещения выполнены внутри `campaigns/VelesNight_2026`; SHA-256 каждого файла после перемещения совпал с исходным. Контрольные суммы сохранены в `import_manifest.json`.

Наличие файлов этапов 3–6 не означает, что эти этапы утверждены или соответствуют нынешнему workflow. На 13.10.2026 пользователь подтвердил только этапы 1–2. Их review остались в исходной папке `../../review/` и побайтно скопированы в `../../pack_001/review/`.

Текущая сборка находится в `../../pack_001/`. Старые `task_choices.json`, `filled_tasks.json`, `quest_group.json` и XLSX из этого архива не используются как её входные данные.
