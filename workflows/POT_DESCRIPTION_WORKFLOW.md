# Pot Description Workflow

Workflow для описания горшков по изображению.

## Когда Включать

Переключай active context в `pot_description`, если пользователь прикрепил изображение и просит описать горшок, короб, подвесной/мини-горшок или грибницу.

Команда для фиксации режима:

```bash
python src/workflow_context.py detect --text "<запрос пользователя>" --apply
```

Если режим не определился, выставить вручную:

```bash
python src/workflow_context.py set --mode pot_description --stage description --notes "Описание горшка по изображению."
```

`workspace/active_context.json` является локальным файлом пользователя и не коммитится.

## Вход

- изображение горшка;
- вид горшка, указанный пользователем;
- при необходимости серия/тематика, если пользователь дал её явно.

Поддержанные виды:

- `Обычный`;
- `Волшебный`;
- `Короб для овощей`;
- `Грибница для грибов`.

`Подвесной` и `мини` считаются обычными горшками для выбора постфикса.

## Выход

Ответ пользователю:

```text
Название:
<название>

Описание:
<короткое описание> <постфикс>
```

Машинный JSON для проверки, если нужно сохранить результат:

```json
{
  "pot_type": "Обычный",
  "title": "Горшок Берёзовый уют",
  "description": "Светлый горшок с простым узором выглядит спокойно и по-домашнему.",
  "postfix": "Выращивай в нём сразу 5 цветов!",
  "final_text": "Светлый горшок с простым узором выглядит спокойно и по-домашнему. Выращивай в нём сразу 5 цветов!"
}
```

## Постфиксы

- `Обычный`: `Выращивай в нём сразу 5 цветов!`
- `Волшебный`: `Выращивай в нём сразу 5 волшебных цветов!`
- `Короб для овощей`: `Выращивай в нём сразу 5 овощей!`
- `Грибница для грибов`: `Выращивай в ней сразу 5 грибочков!`

## Стиль

- описывать только то, что видно на изображении;
- можно добавить мягкую сказочную стилизацию, если она не противоречит изображению;
- стиль теплый, бытовой, сказочный, с легкой иронией;
- текст должен подходить для карточки предмета;
- писать простыми фразами, без чрезмерной метафоричности;
- не делать предмет живым, если это звучит нелепо.

## Запреты

Нельзя выдумывать:

- игровые бонусы;
- ускорение роста;
- проценты;
- прибавку урожайности;
- валюту;
- скрытые свойства;
- механику, которой пользователь не давал.

Плохо:

```text
Этот короб увеличивает урожайность на 20% и приносит больше монет.
```

Хорошо:

```text
Прочный деревянный короб с аккуратными планками выглядит так, будто готов к самой уютной грядке на подоконнике.
```

## Проверка

Если результат сохранен в JSON:

```bash
python src/validate_pot_description.py output/pot_description.json
```

Валидатор проверяет:

- известный `pot_type`;
- правильный постфикс;
- наличие `title` и `description`;
- отсутствие выдуманных игровых механик;
- что `final_text` заканчивается нужным постфиксом.
