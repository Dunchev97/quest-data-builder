# Анкета для диалога и экшена

Для целого quest pack сначала читай `campaigns/<campaign_id>/dialogue_characters.json`, `campaigns/<campaign_id>/<pack_id>/dialogue_plan.json`, утверждённый сценарий и текущие ручные XLSX. Не проси повторно сообщать уже известные значения. Уточни только отсутствующие графические классы/эмоции, фактические направления их ассетов, имя локации, свободные стартовые proto/task ID для новых записей и делегирование сторон/эмоций. Подробный формат и команды — в [workflow подэтапа 6.1](../../../../workflows/DIALOGUE_WORKFLOW.md).

Ниже анкета для отдельной пары файлов.

Заполните пять блоков. Если сведений не хватает, я уточню только недостающее.

## 1. ID

- `id` UI-файла диалога (число): `...`

Это ID самого `UserInterfacePrototype`. У экшена будет отдельный ID.

## 2. Имя файла

- Точное имя: `..._Dialog_1.proto.js`
- Каталог для готового файла: `<game_repo_root>/server/prototypes/user_interface/dialog/<campaign_id>/` (если нужен другой каталог UI-диалогов, укажите его)

Файл содержит JSON, но имеет расширение `.proto.js`. `identifier` будет взят из имени файла без `.proto.js`. Папка `quest_action` предназначена для парного экшена, а не для самого UI-диалога.

## 3. Персонажи и эмоции

Для каждого персонажа:

| Данные | Ответ |
| --- | --- |
| Короткая метка в списке реплик, например `Дед` | `...` |
| Общее отображаемое имя для `speaker_tf`, например `Дед Домовед` | `...` |
| Сторона `left` или `right` | `...` |
| Базовый `view_class` | `...` |
| Эмоция → точный `view_class`, например `радость` → `..._Happy` | `...` |
| Куда исходно смотрит каждый из этих ассетов без `flip`: влево или вправо | `view_class` → `left/right` |
| Начальная эмоция, если не базовая | `...` |

Для одного персонажа сторону можно пропустить: будет `left`. Фактическое направление ассета — отдельное значение от стороны в окне. Если все эмоции смотрят одинаково, достаточно подтвердить это одним ответом. Генератор добавляет `"flip": "horizontal"` только когда это нужно для взгляда в центр; без подтверждённого направления используемого ассета сборка останавливается.

## 4. Реплики

Укажите реплики по порядку, по одной строке на реплику. Количество реплик определю по списку; если есть контрольное число, укажите его отдельно.

```text
Дед (радость): «Домовёнок, глянь, что нашлось.»
Дед (базовая): «Вот Капитан. Дай-ка уголок расправлю.»
Дед (грусть): «Думаешь, ещё приедут?..»
```

Если в какой-то реплике меняется эмоция молчащего персонажа, допишите это после строки: `Другой персонаж: грусть`. Иначе сохранится его предыдущее состояние.

## 5. Экшен, который открывает диалог

- `id` экшена (отдельное число, отличное от ID диалога): `...`
- Точное имя файла: `..._Character_2_Dialog_1.proto.js`
- Каталог для файла: `<game_repo_root>/server/prototypes/quest_action/<campaign_id>/`
- Точная строка `conditions`, например `active_quest=Oseniny_2026_Story_3`: `...`

Остальные поля экшена берутся из образца. Ссылку `stuff_actions[0].identifier` на UI-диалог я подставлю из имени файла диалога.

## Машинный бриф для генератора

ИИ переводит ответы в такой JSON. `key` связывает персонажа с репликами; `name` всегда идёт в `speaker_tf`. `other_emotions` у строки необязателен. Оба каталога передаются генератору через `--output-dir` и `--action-output-dir`.

```json
{
  "id": 2011833,
  "file_name": "Oseniny_2026_Dialog_1.proto.js",
  "expected_line_count": 2,
  "characters": [
    {
      "key": "ded",
      "name": "Дед Домовед",
      "side": "left",
      "emotions": {
        "базовая": "Oseniny_2026_Character_1",
        "радость": "Oseniny_2026_Character_1_Happy",
        "грусть": "Oseniny_2026_Character_1_Sad"
      },
      "asset_facing": {
        "Oseniny_2026_Character_1": "left",
        "Oseniny_2026_Character_1_Happy": "left",
        "Oseniny_2026_Character_1_Sad": "left"
      }
    }
  ],
  "lines": [
    {"speaker": "ded", "emotion": "радость", "text": "Домовёнок, глянь, что нашлось."},
    {"speaker": "ded", "emotion": "базовая", "text": "Вот Капитан. Дай-ка уголок расправлю."}
  ],
  "action": {
    "id": 2011834,
    "file_name": "Oseniny_2026_Character_2_Dialog_1.proto.js",
    "conditions": "active_quest=Oseniny_2026_Story_2"
  }
}
```
