Перед работой убедись, что `description` и `congratulation` соответствуют стилю Домовят из `docs/domovata_style_guide.md`. На этом этапе тексты не переписываются — они дословно берутся из этапа 2, но при проверке quest plan обрати внимание, что механики подобраны по смыслу этих текстов.

ЭТАП 3: ВЫБОР МЕХАНИК (TASK TEMPLATES)

## Цель

Превратить сюжетные квесты из этапов 1-2 в план игровых заданий. Для каждого квеста выбрать 3 task template ID, которые по смыслу подходят к description и congratulation.

`python src/workflow_fast.py stage3 ...` автоматически создает `review/stage3_review.md`. Человек правит только review. `workflow_fast.py approve --stage 3 ...` применяет его в `stage3_quests.txt`, заново собирает `quest_plan*.json`, валидирует результат и сохраняет checksum review.

## Что делает ИИ

- Читает `title_quest`, `description`, `congratulation`, `Character` из этапа 2.
- Выбирает 3 шаблона (TT-001..TT-034) по смыслу текста.
- Указывает `Task template ID`, русское название, `Task type`.
- Проверяет ограничения (см. ниже).

## Что ИИ НЕ делает

- Не переписывает description/congratulation (они идут из Stage 2).
- Не выбирает конкретные garbage/flower/collection.
- Не заполняет JSON Tasks.
- Не делает CSV.

## Как выбирать механику

Смотри на текст квеста и выбирай шаблон по смыслу:

| Сигнал в тексте | Подходящий шаблон |
|----------------|-------------------|
| "поговори", "знакомство", "расскажи", "узнай" | TT-001 Диалог |
| "собери", "найди", "спрятано", "потерялось" | HOG (TT-003..TT-007) |
| "сделай", "создай", "собери механизм", "смастерь" | TT-002 Крафт |
| "отдай", "передай", "примени", "зажги", "почини объект" | TT-033 Передача предмета |
| "убери", "прибери", "мусор", "уборка" | TT-020 / TT-021 Уборка мусора |
| "собери цветы", "растение", "посади" | TT-018 / TT-019 Сбор цветов |
| "попроси", "друзья помогут", "нужна помощь" | TT-008 ASK или TT-009 PER |
| "загадка", "тайна", "угадай" | Mystery (TT-022..TT-027) |
| "сфотографируй" | TT-034 Фото |

Правило: если квест про "починить печь" — Крафт или Передача. Если про "найти рубин" — HOG. Если про "заблудился" — Диалог + Уборка пути.

## Ограничения (проверить перед ответом)

1. **Крафт/Передача (TT-002/TT-033):** примерно 1 раз на 3-4 квеста. Финал pack часто с крафтом или фото.
2. **ASK/PER (TT-008/TT-009):** только в квестах с крафтом или передачей. Чередовать: ASK → PER → ASK.
3. **HOG (TT-003..TT-007):** не ставить в соседних квестах (минимум 1 квест между HOG).
4. **Dialog/Photo (TT-001/TT-034):** максимум 1-2 раза на pack. Не в финале, если там уже крафт/фото.
5. **Один шаблон:** не более 2-3 раз во всём pack (исключение: Уборка мусора/цветы как базовая механика).

## Рекомендации по размеру pack'а

### Короткий (3-6 квестов)
- Крафт: 1 раз (обычно в середине или конце).
- HOG: 1 раз.
- Dialog: 1 раз (начало).
- Остальное — уборка, цветы, collection.

### Средний (7-10 квестов)
- Крафт: 2 раза (например Q3 и Q8).
- HOG: 2 раза (Q2 и Q7).
- Dialog: 1-2 раза.
- Mystery или Silhouette: 1 группа.

### Большой (11-15 квестов)
- Крафт: 3 раза (Q4, Q8, Q12 или финал).
- HOG: 3 раза.
- Dialog: 2 раза.
- Mystery: 1 группа из 3 заданий.
- Silhouette: 1 группа из 2-3 заданий.

## Формат выхода (один квест)

```text
Classname quests: [Префикс]_Story_[Номер]
title_quest: [Название]
№ quest: [Номер]
№ task: [Номер*3-2] [Номер*3-1] [Номер*3]
Task template ID: [TT-XXX] / [TT-XXX] / [TT-XXX]
Task template name: [Русское название] / [Русское название] / [Русское название]
Task type: [машинный тип] / [машинный тип] / [машинный тип]
description: "[Дословно из Старт: Stage 2]"
Tasks:
[пусто на этом этапе]
congratulation: "[Дословно из Завершение: Stage 2]"
Character: [Имя персонажа]
```

Правила форматирования:
- `description` и `congratulation` — дословно из Stage 2, без сокращений.
- Разделитель между заданиями: ` / `.
- Количество элементов в трёх строках одинаковое.

## Быстрый чек-лист (проверить в конце)

- [ ] Крафт/Передача примерно каждые 3-4 квеста
- [ ] ASK/PER чередуются и только с крафтом/передачей
- [ ] HOG не в соседних квестах
- [ ] Dialog/Photo ≤ 2 раза, не в финале с крафтом
- [ ] Один шаблон не повторяется >3 раз (кроме базовых уборок/цветов)
