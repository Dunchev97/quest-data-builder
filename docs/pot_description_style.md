# Pot Description Style

Краткая памятка workflow `pot_description`.

Вход:

- картинка горшка;
- вид горшка.

Выход:

- короткое описание в стиле проекта;
- название горшка;
- правильно указанный постфикс по виду горшка.

Постфиксы:

- Выращивай в нём сразу 5 овощей! - для коробов для овощей
- Выращивай в нём сразу 5 волшебных цветов! - для волшебных горшков
- Выращивай в нём сразу 5 цветов! - для обычных, подвесных, мини горшков
- Выращивай в ней сразу 5 грибочков! - для грибниц

Правила:

- описывать только то, что видно на изображении, плюс мягкую стилизацию под мир игры;
- не выдумывать игровые свойства, бонусы и механику без отдельного запроса;
- стиль: теплый, сказочный, бытовой, с легкой иронией;
- описание должно быть пригодно для карточки предмета.
- подробный workflow: `workflows/POT_DESCRIPTION_WORKFLOW.md`;
- JSON-результат можно проверить командой `python src/validate_pot_description.py output/pot_description.json`.
