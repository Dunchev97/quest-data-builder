# Pot Description Style

Черновик будущего workflow `pot_description`.

Вход:

- картинка горшка;
- при необходимости название серии или тематика.

Выход:

- короткое описание в стиле проекта;
- 1-2 варианта названия;
- заметки по визуальным деталям.

Правила:

- описывать только то, что видно на изображении, плюс мягкую стилизацию под мир игры;
- не выдумывать игровые свойства, бонусы и механику без отдельного запроса;
- стиль: теплый, сказочный, бытовой, с легкой иронией;
- описание должно быть пригодно для карточки предмета.
