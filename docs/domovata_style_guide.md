# Стиль текста Домовят

Этот гайд описывает единый стиль текстов quest workflow для игры "Домовята". Все description, congratulation, dialogue_replica, quest_group и другие тексты, которые пишет ИИ, должны соответствовать этим правилам.

---

## Основные принципы

### 1. Тёплое обращение к игроку

Игрок — это друг, сосед, помощник. Никаких формальных обращений.

**Хорошо:**
- Домовёнок, беда!
- Эх, домовятушка...
- Дорогой друг
- Дружок
- Друг мой

**Плохо:**
- Игрок
- Пользователь
- Вам необходимо
- Требуется выполнить

### 2. Description — это история, а не инструкция

Description должен объяснять, **что случилось** и **почему нужна помощь**, а не просто перечислять действия.

**Плохо:**
```
Собери 5 яиц. Они спрятаны в лесу.
```

**Хорошо (Леший):**
```
Домовёнок, беда! Я покрасил яйца под цвет мха — теперь найти не могу куда я их отложил! Помоги собрать, а то я без крашеных яиц на пасху окажусь...
```

**Хорошо (Ведятя):**
```
Дорогой друг, Велесова ночь близко. В эту ночь мы должны подготовить наш дом, чтобы встретить духов с уважением и почетом. Поможешь нам прибраться и украсить дом?
```

### 3. Congratulation — благодарность + позитивный итог

Всегда благодарит игрока. Даёт или смешной, или тёплый итог. Никогда сухого "Задание выполнено".

**Плохо:**
```
Квест завершён. Получите награду.
```

**Хорошо:**
```
Вот это да! Спасибо, дружок! Теперь хоть кулич на фоне не потеряется!
```

**Хорошо:**
```
Может мне теперь курятник построить?
```

**Хорошо:**
```
Благодарю тебя, дом теперь сияет. Велес будет доволен нашим трудом.
```

### 4. Персонажи имеют разные голоса

Каждый персонаж говорит по-своему. При генерации текста ориентируйся на эти архетипы:

| Архетип | Черты речи | Пример |
|---------|-----------|--------|
| **Баба Яга** | Забывчивая экспериментаторша, удивляется последствиям своих зелий. Часто "Ну, дружок..." или "Эх, домовятушка..." | "Ну, дружок, переборщила я с лунными кристаллами увеличения... Теперь это чудо даже в котёл не влезает!" |
| **Леший** | Простой, немного боязливый, боится остаться без гостей. "Домовёнок, беда!" | "Домовёнок, беда! Тропу к моей поляне осока с папоротником захватили!" |
| **Кощей** | Тщеславный, грандиозные планы, любит показать величие. "Достиг я величия, домовёнок!" | "Достиг я величия, домовёнок! Моя краска для яиц великолепно блестит, но есть побочный эффект..." |
| **Ведятя / Мудрый старик** | Спокойный, важный, но не сухой. Обращается уважительно. | "Дорогой друг, Велесова ночь близко..." |
| **Добродушный сосед** | Простой, может ворчать, но добрый. | "Кхе-кхе! Слышь, домовой! Мы с ребятами на природу собираемся..." |

Если в pack новые персонажи, определи их голос на этапе 1 и придерживайся его во всех репликах.

### 5. Конфликт — добродушный хаос, не зло

Проблемы в квестах возникают из-за:
- Перепутанных рецептов
- Экспериментов, вышедших из-под контроля
- Забывчивости
- Природного хаоса

Никогда не делай конфликт злобным, угрожающим или депрессивным. Даже эпика (Велесова ночь) решается через уют дома и помощь соседям.

**Хорошо:**
- Яга перепутала рецепт — изба в кислотных цветах
- Кощей потерял ключ от сокровищницы
- Дед хочет сфотографировать пикник, но забыл куда положил фотоаппарат

**Плохо:**
- Враг захватил деревню, нужно воевать
- Мир на грани уничтожения
- Всё пропало, безнадёжно

### 6. Магия вплетена в повседневность

Магия, технологии, невероятные события — это нормально. Но они всегда проявляются через бытовые ситуации:

- Лунные кристаллы увеличили яйцо → не влезает в котёл
- Зелье быстрой покраски → приманило зайцев
- Лунная пыль в куличе → кулич светится как фонарь
- Космический корабль упал → нужно помочь инопланетянину, накормить чаем

### 7. Избегать формальных и абстрактных фраз

**Никогда не писать:**
- "Необходимо"
- "Требуется"
- "Вам нужно"
- "Задание:"
- "Миссия:"
- "Цель:"

**Всегда писать живо:**
- "Поможешь?"
- "Нужно бы..."
- "А то..."
- "Без тебя не справлюсь"

### 8. Congratulation может намекать на продолжение

Если pack не заканчивается полностью, congratulation может мягко намекнуть, что впереди ещё работа:

```
Теперь духи знают, что здесь их ждут. Но помни, это только малая часть нашей подготовки.
```

```
Чернобог хотел обмануть нас, но ты разрушил его замыслы. Тьма ослабела, но не исчезла... будь начеку
```

## Контр-примеры: плохо → хорошо

### Description

**Плохо:**
```
Соберите 5 веток для костра. Они лежат в лесу.
```

**Хорошо:**
```
В эту ночь мы зажжём костёр в честь Велеса. Огонь его защитит нас от тёмных духов, пока они не вернутся обратно в Навь. Собери сухие ветви и травы, чтобы костёр горел до самого утра.
```

### Congratulation

**Плохо:**
```
Задание выполнено. Вы получаете награду.
```

**Хорошо:**
```
Отлично. Из скорлупы можно стулья сделать или баню перекрыть, ещё подумаю...
```

### Dialogue (TT-001)

**Плохо:**
```
РЕПЛИКА ДИАЛОГА: Персонаж рассказывает о сюжете. Игрок должен слушать.
```

**Хорошо:**
```
Граница между миром Яви и Нави истончается, скоро Чернобог обретет великую силу. Чтобы защитить границу миров, Велес — страж завесы, распорядился провести обряды защитные. Помоги нам мир Яви сберечь.
```

### Quest Group

**Плохо:**
```
Вам предстоит выполнить серию заданий по подготовке к празднику. Необходимо собрать ресурсы и крафтить предметы.
```

**Хорошо:**
```
Вы догоняете отважную воительницу на пути к краю света. Вместе вам предстоит перехитрить Движущийся лес, разгадать тайну Бездонной пропасти и решить, что делать, когда грозный зверь просит помощи, а не боя.
```

## Как использовать этот гайд

- **Перед генерацией** любых текстов на этапах 1, 2, 4, 5 прочитай этот гайд.
- **После написания** текста проверь его по чек-листу ниже.
- Если campaign имеет свой `campaign_tone.md` — базовый стиль Домовят **не отменяется**, а дополняется campaign-specific деталями (словарь, запреты, тема).

### Быстрый чек-лист перед approval

- [ ] Description объясняет проблему, а не перечисляет действия
- [ ] Есть тёплое обращение (домовёнок / дружок / друг мой)
- [ ] Congratulation благодарит и даёт позитивный/смешной итог
- [ ] Персонаж говорит в своём характерном голосе
- [ ] Нет формальных слов (необходимо, требуется, игрок)
- [ ] Конфликт — добродушный хаос, не зло
- [ ] Магия/технологии проявляются через быт

---

## Связь с campaign_tone.md

Если `campaigns/<campaign_id>/campaign_tone.md` существует:

1. Базовый стиль Домовят (этот гайд) остаётся основой.
2. `campaign_tone.md` добавляет:
   - Campaign-specific словарь (например: "табакерка", "заводной ключик")
   - Campaign-specific запреты (например: "не делать расследование")
   - Тематические рамки (например: "механический городок", "славянская эпика")
3. Всегда совмещай: тон Домовят + тон campaign.

**Пример совмещения:**
- Campaign: Велесова ночь (славянская эпика, мистика)
- Тон Домовят: ламповый, тёплый, через помощь соседям
- Результат: "Дорогой друг, Велесова ночь близко. В эту ночь мы должны подготовить наш дом..." — эпическая тема, но тёплый бытовой уголок.
